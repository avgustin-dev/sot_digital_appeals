# Статичные тексты

Это **источник** копирайта для фронта и пример для Java-бэкенда (`GET /public/bootstrap`).

Приложение читает эти JSON (`src/lib/catalog.ts`). Правки текстов — здесь, не в TypeScript.

| Файл | Что внутри |
| --- | --- |
| `site.json` | Публичный сайт: навигация, руководство, контакты, правила |
| `ui.ru.json` / `ui.ky.json` | Интерфейс RU / KY |
| `booking-rules.json` | Правила записи |
| `eligibility-tree.json` | Дерево допуска / отказов |
| `survey.json` | Анкета (мета + вопросы) |
| `calendar-rules.json` | Текст правил календаря |
| `shell.json` | 404, ошибка сервиса, PDF |
| `dictionaries.json` | Справочники |

Заявки и учётки сюда не входят.
