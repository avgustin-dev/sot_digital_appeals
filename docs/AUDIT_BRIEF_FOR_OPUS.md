## 2. Суть продукта (бизнес)

### Название / цель
**Цифровая платформа приёма граждан руководством Верховного суда Кыргызской Республики.**

Не общий «сайт суда» и не e-filing дел.  
**Личный приём руководством** (председатель / зам.) + полный цикл сопровождения обращения.

### Источник требований
Внутреннее **предложение** (сканы/текст у владельца). Ключевые этапы:

1. **Регистрация** — предварительная **онлайн-запись** на приём (сайт ВС), правила записи, уведомление о подтверждении.  
2. **Анализ** — предварительное изучение, **электронная карточка** обращения (данные, суть, категория, история).  
3. **Личный приём** — изложение, разъяснение, **поручение**, ответственный, при необходимости профильные сотрудники.  
4. **Контроль** — «ответственный по обращению», исполнение, ответ в срок.  
5. **Обратная связь** — оценка приёмной (QR/форма): уважение, ясность дальнейших действий, удобство, сроки ответа.  
6. **Мониторинг повторных** обращений — темы, системные проблемы.

### Жёсткие границы приёма
**На приёме НЕ обсуждаются:**
- конкретные судебные дела;
- законность судебных решений;
- результаты рассмотрения дел.

**Можно:** организация судопроизводства, деятельность суда, предложения по законодательству КР; письменное обращение на приёме.

**Принцип:** обращение услышано, рассмотрено, разъяснены права; **независимость судей** сохраняется полностью.

### Слоты (рукопись)
Интервалы **20 минут** приём + **5 минут** перерыв, например:  
`08:00–08:20`, `08:25–08:45`, `08:50–09:10`…  
Данные: **ФИО**, **тело/тема приёма**, **календарь** (кол-во дней, время, перенос).

### Где жить в проде (контекст)
Реальный портал ВС: **https://sot.kg/**  
Идея: **раздел** «приём граждан» (не отдельный «весь сайт»).  
Макет «полного sot.kg» **откатывали** — сейчас это **самостоятельное демо-приложение** платформы.  
Не возвращать оболочку-копию sot.kg без запроса.

### Цель
Собрать **ссылки и данные** по системам, **из которых можно что-то взять** для платформы **личного приёма / записи / обращений** при верховном (или высшем) суде.

### Что искать (типология)
| Тип | Описание |
|-----|----------|
| A | Личный / онлайн-приём **руководства** суда |
| B | Онлайн-запись к аппарату / клерку / service bureau (слоты) |
| C | Visitor / туры / e-pass (второстепенно) |
| D | E-filing / судебный кабинет |

| F | Гос-ID / единое окно |
