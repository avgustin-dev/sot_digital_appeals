# Цифровая платформа приёма граждан — Верховный суд КР

Демонстрационный стенд по предложению о многоэтапном приёме граждан руководством ВС КР.

Подробнее: [ARCHITECTURE.md](./ARCHITECTURE.md)

## Среда выполнения

| | Версия |
|--|--------|
| **Node.js (рекомендуется)** | **26.x** (Current / upcoming LTS) |
| Файл `.nvmrc` | `26` |
| `engines.node` | `>=26.0.0` |

Проверка:

```bash
node -v   # желательно v26.x
```

Установка Node 26 (пример через nvm-windows / fnm):

```bash
nvm install 26
nvm use 26
```

> **Примечание:** на машине разработки может стоять Node 24 LTS. Проект собирается и на 24+, но для соответствия 2026 зафиксирован **Node 26**.

## Модель продукта

```
[ Портал ВС / судов ]  --ссылка-->  [ Этот сервис: запись на приём ]
                                         │
                                         ├─ 1–2. Фильтр по вариантам (как sud.gov.kz)
                                         ├─ отказ с официальным текстом  ИЛИ
                                         ├─ ФИО, тема, слот 20 мин (предложение + рукопись)
                                         └─ staff: анализ → приём → контроль → ОС → мониторинг
```

**Предложение руководства** — полный цикл и предмет приёма.  
**Казахстан** — допуск radio + отказ.  
**«По-кыргызски»** — KY/RU, PIN-самообслуживание, слоты 20+5, прозрачный цикл после записи.
